# ReplayTrade 易用性改造需求（2026-11-19）

## 背景

用户（Fish）使用本工具做 K 线复盘训练，反馈四类核心痛点：交易记录不能沉淀、持仓止盈止损不可修改、下单交互繁琐、画图工具难用。本文档定义六项改造的最终形态与验收标准，实施严格按本文档执行。

---

## 需求一：回放批次（Replay Sessions）

### 功能
- 每次回放**若有成交**，自动归档为一批，持久化到 localStorage（key: `replaytrade:sessions`）
- 封批时机（同批只封一次，防重复）：
  - 回放完成时
  - 退出回放时
  - 开始新回放（beginReplayRun）前，先封上一批
- 批记录字段：`id / symbol / timeframe / startedAt / endedAt(封批时刻ms) / replayStartTime(回放起点K线时间秒) / startingBalance / finalBalance / totalPnl / trades: ClosedTrade[]（含 openedAt）`
- 上限 200 批，超出淘汰最老

### UI
- 底部新增「回放记录」tab（与持仓/历史成交/统计/会话并列）
- 列表行标题：`BTC/USDT · 5m · 08-01→11-18 · 12 笔 · +3.2R`（区间=回放起点→最后成交时间），按封批时间倒序；操作：详情 / 删除
- 详情（行内展开）：本批成交表（复用 TradeHistory）+ 本批统计（胜率/净盈亏/盈亏比/平均R/最大回撤，从 trades 离线重算；权益曲线从累计已实现盈亏生成）+ 导出 CSV + 删除本批
- 列表头部「清空全部」（二次确认）

### CSV 导出
- 表头：`序号,代码,方向,数量,开仓价,开仓时间,平仓价,平仓时间,盈亏,收益率(%),R,平仓原因`
- UTF-8 带 BOM，Excel 直开不乱码；文件名 `replaytrade_BTCUSDT_5m_20260801-20261118.csv`

### 验收
- 三种封批途径都产生批次；刷新页面批次仍在
- 无成交的回放不产生批次；删除/清空即时生效
- 批内统计只含本批成交；导出内容与表格一致

## 需求二：历史成交补开仓时间

- `ClosedTrade.openedAt` 字段已存在，仅 UI 未展示
- 成交表在「平仓时间」前加「开仓时间」列，格式 `YYYY-MM-DD HH:mm`

### 验收
- 每行同时显示开仓、平仓两个时间

## 需求三：图表拖动修改 SL/TP

### 交互
- 鼠标距任一持仓的 SL/TP 价格线 ≤6px：光标变 `ns-resize`
- 按住拖动：线实时跟随，线上显示当前价位
- 安全侧钳制：多单 SL ≤ min(开仓价, 现价)、多单 TP ≥ 开仓价；空单镜像。越界钳到边界
- 松手写回持仓；**Entry 线不可拖**
- 回放播放中允许拖动（后续 K 线按新值撮合）

### 技术落点
- TradingChart pointer 事件前置命中检测（priceToCoordinate），命中则拦截、不传给 DrawingEngine
- usePaperTrading 新增 `updatePositionLevels(id, {stopLoss?, takeProfit?})`
- 修复现存 bug：priceLine effect 对已有线不 applyOptions 同步新值（改值后线不动）

### 验收
- 拖动松手后：持仓面板数字、图上虚线、后续撮合三者一致
- 拖不出安全侧

---

## 需求四：交易面板双按钮 + 免确认

### 交互
- 底部两个大按钮：**买入/做多**（绿）、**卖出/做空**（红），两列等宽
- 点击即以按钮方向下单：校验/预览用 `{...draft, direction: 按钮方向}` 现算，不依赖异步 state；同时同步内部方向 state
- 顶部多/空切换保留：控制风险快捷键的计算方向与预览区
- 「下单免确认」复选框（localStorage: `replaytrade:skip_confirm`）：勾选→点大按钮直接成交 + toast；未勾→弹确认框（确认框按按钮方向显示）

### 验收
- 免确认勾选时，点按钮一击成交，方向与按钮一致（与顶部切换无关）
- 快捷键按顶部切换方向计算
- 免确认偏好刷新后保留

---

## 需求五：画图交互三件套

1. 画完任意图形**自动切回「选择/移动」工具**（图形保留，立即可点选/拖动编辑）
2. 图表上**右键**：取消进行中的绘制并切回选择工具（preventDefault，不弹浏览器菜单）
3. **磁吸默认关**（off），按钮三档循环保留

### 验收
- 画完趋势线自动回选择态，点该线可选中拖动
- 绘制中右键立即取消回选择
- 新会话磁吸默认关

---

## 需求六：仓位工具两步画 + 标注汉化

### 交互
- 多头仓位 / 空头仓位 / 风险收益比：点击数 3→2（点入场、点止损），第三点（止盈）自动按 2R 外推；画完可拖手柄调

### 汉化（DrawingRenderer.renderPosition 标注）
| 原文 | 中文 |
|---|---|
| Entry | 开仓 |
| SL | 止损 |
| TP | 止盈 |
| Risk | 风险 |
| Reward | 收益 |
| R:R | 盈亏比 |
| Position size | 仓位大小 |
| `Risk $x (y% of $z)` | `风险 $x (y% · 资金 $z)` |

### 验收
- 两击画出完整仓位图（含自动止盈位）
- 图上标注全部中文

---

## 实施顺序

1. 需求二（最小）→ 2. 需求五 → 3. 需求六 → 4. 需求四 → 5. 需求三 → 6. 需求一（最大）

每步 `npm run build`（tsc + vite）通过后再进下一步。

## 风险与边界

- localStorage 5MB：200 批 × ~10KB 远低于上限
- 免确认误触：toast 即时可见、可立即平仓，模拟盘无真实资金风险
- 拖 SL/TP 与回放推进并发：以最后写入值为准，符合真实交易语义

# 第二轮迭代（2026-11-19 凌晨验收反馈）

## 需求七：回放记录备注字段
- 每批可自由填写备注，列表行标题后展示；可编辑（铅笔按钮 → 行内输入，回车/失焦保存）
- 存储：`ReplaySessionRecord.note?: string`，localStorage 持久化
- 验收：备注保存后刷新仍在；列表名称后可见

## 需求八：从开仓线拖出 SL/TP
- 持仓未设 SL/TP 时，按住开仓（Entry）线上下拖动即"拖出"：
  - 拖向风险侧（多单下方/空单上方）→ 生成止损；拖向盈利侧 → 生成止盈
  - 拖动方向首次确定后本次拖拽固定该字段，实时跟手，松手生效
- 光标：悬停开仓线 ns-resize；安全侧钳制沿用 updatePositionLevels
- 验收：无 SL/TP 的持仓可从开仓线一次拖出对应线

## 需求九：仓位工具 TV 式单击成形 + 全区域拖动
### 交互
- 多头/空头仓位、风险收益比：**单击一次即成形**（点击处=入场，止损默认 1%，止盈 2R），成形后自动回光标模式
- 命中区域从"边线 ±容差"扩为**整个填充 bbox**：区域内任意点按住即可整体拖动
### 根因（代码实锤）
- multipoint 模型 onPointerDown 只攒点不 commit，须双击（onDblClick）才提交——双击自身又追加歪点
- DrawingHitTest 对 position 类只做边线距离命中
### 验收
- 点一下仓位工具再点一下图：仓位图立即出现、止盈止损自动放好、光标已回选择态、区域任意处可拖

---

# 第三轮迭代（2026-11-19 01:31 反馈）

## 需求十：画图工具栏拍平
- 工具按钮全部平铺一级（线条/形状/标注/仓位四组间加分隔线），取消二级菜单
- 验收：任一工具一次点击即激活

## 需求十一：仓位图单击成形的宽度与位置
- 根因：补点 time 与入场点相同 → 三点同一 x 坐标 → 渲染成竖线
- 修法：止损/止盈点 time = 入场 time + 12 根（tfSeconds），形成入场在鼠标处、向右展开的矩形
- 验收：点击处出现带宽度的仓位矩形，入场边在鼠标位置

## 需求十二：图形设置浮窗可拖动
- 设置面板标题栏按住可拖到任意位置（fixed 定位跟随），不再钉死左下
- 验收：拖动后松手面板停在新位置，可继续操作

## 需求十三：交易面板去顶部方向 tab
- 顶部买入/卖出切换删除；方向由底部大按钮 hover（桌面）/点击（触屏）驱动，快捷键与预览跟随
- 验收：面板更简洁；hover 哪个按钮快捷键就按哪个方向算；下单方向与按钮一致
